# Social Media Post Generator (HTML-to-Carousel)

A tool that converts standard HTML and CSS into PNG images for social media posts.

## Features
- Renders HTML/CSS to PNG directly in the browser.
- Pre-configured aspect ratios (1:1, 4:5, 9:16, 16:9).

## Tech Stack
- **Frontend:** React, Vite
- **Backend:** .NET
- **Rendering:** html-to-image
